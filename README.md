# 가을을 담다 · GitHub Pages 배포

1. GitHub에서 autumn-concert라는 공개(Public) 저장소를 만듭니다.
2. 이 압축파일을 풀고 index.html, assets 폴더, .nojekyll, README.md를 저장소 최상위에 업로드합니다. ZIP 자체를 업로드하지 마세요.
3. Settings → Pages → Build and deployment에서 Source를 Deploy from a branch로 선택합니다.
4. Branch는 main, 폴더는 /(root)를 선택하고 Save를 누릅니다.
5. 배포가 완료되면 Pages 화면의 Visit site 링크를 엽니다.

기본 주소: https://GITHUB-ID.github.io/autumn-concert/

파일 구조: index.html과 assets 폴더가 같은 위치에 있어야 합니다.
수정할 때 같은 파일을 교체하고 커밋하면 Pages가 다시 배포됩니다.
이 사이트는 공개되며 열람에 ChatGPT 로그인이 필요하지 않습니다.
